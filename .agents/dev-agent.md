开发会话读 `00-index.md`，按下表定位到对应小节（同文件内跳读即可）：

| 小节 | 主题 |
|---|---|
| 1 | 技术栈、目录分层、允许改动边界 |
| 2 | 状态机、BR/E 矩阵、不变量、并发防御 |
| 3 | service 实现模式（条件 UPDATE/幂等/闸门/留痕） |
| 4 | 工作项、分支、提交规范、提交前门禁 |
| 5 | config.yaml shop 段、demo-mode、部署与本地运行 |
| 6 | 覆盖率门禁、race、安全基线、红线 |
| 7 | 提交前自检清单、交接格式 |
| 8 | 需求矛盾裁决、只读对象清单、编码例外 |
| 9 | 缺陷修复流程、教训库 |
