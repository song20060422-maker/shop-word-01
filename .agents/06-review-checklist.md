# 06 · 自检清单与交接格式

## 提交前自检（逐项打勾）

- [ ] gofmt 空输出、vet/build/test 全过、exit 0
- [ ] 状态跃迁全部"条件 UPDATE + RowsAffected 校验"，无先读后写
- [ ] 并发路径有闸门与并发测试（渠道调用计数断言）
- [ ] DB 错误分类：仅唯一键冲突映射业务重复错误
- [ ] 覆盖率单命令复跑未低于基线（service/api ≥85%）
- [ ] 测试钩子未被裸露到生产路径（demo-mode 门禁仍在）
- [ ] 提交编号在 `docs/dev_log.md` 存在；类型与内容匹配
- [ ] `docs/events.md` 登记本次会话事件
- [ ] INV-1~4 复核通过（给数字）

## 交接固定格式

1. 工作项：T 编号 + 覆盖的 BR/AC 编号
2. 变更：文件、接口、表；框架新增/修改边界
3. 自测：命令 + 输出摘要 + 退出码 + 覆盖率
4. 判据：按 AC 逐条对照（未通过写原因）
5. 不变量：INV-1~4 数字
6. 风险与待确认：假设编号、需裁决项
7. 下一步：下一工作项与依赖

## 缺陷记录落点

`docs/review_records.md`：问题 → 修正要求 → 复测证据，修完再交。
