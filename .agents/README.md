本目录存放各 Agent 的提示词，按版本归档，**任何修改都不覆盖旧版**。

```text

├─ dev-agent.md              # 当前生效版本（与 versions 中最新版内容一致）
├─ README.md                 # 本文件：版本索引、加载记录、保留规则
└─ versions/

```

## 保留与变更规则

1. 修改提示词时：先新增 `versions/<agent>.vN.md`，再更新 `dev-agent.md` 与上表，**禁止就地覆盖历史版本**。
2. 每次变更写明：改了什么、为什么改、对应哪个需求编号或工作项、是否经学生确认。
3. 提交格式：`[类型] [版本号] [T编号] 描述`，T 编号取自 `docs/dev_log.md` 工作项清单。
4. 提示词不替代 `AGENTS.md`：约束冲突时以 `AGENTS.md` 为准（其中的旧提交格式条款待学生修订）。
5. 历史版本只读，不得删除；废止某版本时在上表标注“已废止 + 原因”。

## 与交付证据的对应

- 共同要求要求提交“约束文件历史版本、实际加载或读取记录及对应任务”：本目录的 `versions/` 与“加载记录”表即对应证据。
- 开发会话导出中应能定位到“何时加载了哪一版”，并与本表一致。
